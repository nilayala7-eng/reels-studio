# Estudio de reels

Edición de reels con Claude + Remotion, 100 % gratis:
- Transcripción palabra a palabra (Parakeet v3 / sherpa-onnx), sin conexión.
- Corte automático de silencios con ffmpeg.
- Plantilla Remotion: subtítulos animados, etiquetas, stickers, zooms y escenas de motion graphics (pasos, checklist, logos, versiones, diagramas, terminal).

Instalación: `npm install && pip install sherpa-onnx yt-dlp` y descarga el modelo (ver `CLAUDE.md`).
Uso: mira `CLAUDE.md`; el estilo está en `estilo.md`.
