# Reels de referencia

Hay un fotograma por segundo en cuadrículas de 6×2: cada imagen cubre 12 s y se lee de izquierda a derecha y de arriba abajo. `transcripcion.txt` tiene lo que se dice, con tiempos.

- **ref1**: https://www.instagram.com/p/DeY-0Zhxe9u/ (67 s). Estilo A: hablar a cámara con título fijo, etiquetas apiladas y stickers.
- **ref2**: https://www.instagram.com/p/DeCFKLUsQPM/ (43 s). Estilo B: limpio, blanco y azul, alternando con escenas de motion graphics.

Para volver a descargarlos: `python -m yt_dlp -o "refs/%(id)s.%(ext)s" <url>`.
